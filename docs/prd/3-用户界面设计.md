# 3. 用户界面设计目标

## 3.1 总体UX愿景
愿景是创建一个 **简洁、清晰、高效** 的管理工具。界面应直观，让用户能以最少的精力快速获取关键信息，并轻松完成核心的增删改查操作。**确保核心操作步骤明确无误**。

## 3.2 核心交互模式
* **数据驱动的看板**
* **简洁的表单录入**
* **即时的数据筛选与排序**

## 3.3 核心屏幕与视图
1. **资产看板 (Asset Dashboard)**
2. **证书录入/编辑表单 (Certificate Add/Edit Form)**

## 3.4 可访问性 (Accessibility)
* **根据您的指示，此项暂不作为MVP阶段的强制要求**。

## 3.5 品牌 (Branding)
* **主色调采用"平安橙"作为系统的强调色和品牌色**。
* **整体风格要求页面简洁，避免不必要的视觉元素干扰**。

## 3.6 目标设备与平台
* **MVP阶段仅需支持桌面端浏览器（PC），无需考虑移动端或平板的响应式设计**。
