# 4. 技术假设

## 4.1 仓库结构 (Repository Structure)
采用**单体仓库（Monorepo）**模式，以简化单个开发者的本地联调工作。

## 4.2 服务架构
采用基于"DDD分层"的**单体（Monolithic）架构**。

## 4.3 测试要求
开发过程将遵循**TDD（测试驱动开发）**模式。所有核心业务逻辑的**单元测试覆盖率必须达到80%**。集成测试需覆盖关键API端点。前端测试框架使用 **Jest**。

## 4.4 其它技术假设与要求
* **后端**: Java JDK 8, Spring Boot 2.7.x, MybatisPlus 3.5.x。
* **后端构建**: **Maven**。
* **前端**: Vue 3.x。
* **数据库**: MySQL 8.0。
* **API规范**: **Swagger 3.0.x**。
* **API响应**: 所有API接口必须返回**统一结构的响应体**。
