# Story 1.2: TDD环境与CI流水线基础

## Status: Archived

## Story

- As a 开发者
- I want 配置好测试驱动开发(TDD)所需的环境，以及一个基础的持续集成(CI)流水线
- so that 我从项目一开始就能保障代码质量并自动化构建与测试

## Acceptance Criteria (ACs)

1. 后端模块中集成了JUnit 5等测试框架，并配置好TDD开发流程
2. 前端模块中集成了Jest测试框架
3. 代码仓库中配置一个基础的CI脚本(如GitHub Actions)，在代码提交时能自动执行前后端的单元测试
4. 测试覆盖率工具已集成，并设定了80%的目标

## Tasks / Subtasks

- [x] 配置后端测试环境 (AC: 1)
  - [x] 集成JUnit 5测试框架
  - [x] 配置TDD开发流程
- [x] 配置前端测试环境 (AC: 2)
