# 8. 源代码结构 (Source Code Structure)

```
cert-manager/
├── apps/
│   ├── admin/            # 管理后台前端(Vue3)
│   └── api/              # 后端服务(Spring Boot)
├── libs/
│   ├── common/           # 公共工具类
│   ├── domain/           # 领域模型
│   └── infrastructure/   # 基础设施层
├── docs/                 # 文档
└── scripts/              # 部署脚本
```

## 8.1 核心模块职责
- **admin**: 提供证书管理的Web界面
- **api**: 实现RESTful API和业务逻辑
- **domain**: 包含证书管理的核心领域模型
- **infrastructure**: 数据库访问和外部服务集成
