# 7. 数据库表结构 (Database Schema)

## 7.1 certificates 表
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 证书唯一标识 |
| domain | VARCHAR(255) | NOT NULL, UNIQUE | 证书域名 |
| issuer | VARCHAR(50) | NOT NULL | 颁发机构 |
| expiry_date | DATETIME | NOT NULL | 过期时间 |
| status | ENUM('active','expired') | DEFAULT 'active' | 证书状态 |

## 7.2 certificate_history 表
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 历史记录ID |
| certificate_id | VARCHAR(36) | FOREIGN KEY | 关联证书ID |
| operation | VARCHAR(20) | NOT NULL | 操作类型 |
| operated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 操作时间 |
