# 2. 技术栈

## 2.1 云基础设施
- **[建议]** 对于MVP阶段，为了控制成本和简化部署，我建议将前后端和数据库统一部署在**一台云服务器（Linux VPS）**上。

| **类别** | **技术选型** | **版本** | **用途** |
