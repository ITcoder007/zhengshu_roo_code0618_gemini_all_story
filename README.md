# 证书管理系统

## 项目结构
- `backend/`: Spring Boot后端服务
- `frontend/`: Vue 3前端应用
- `docs/`: 项目文档

## 开发环境要求
- JDK 11+
- Node.js 16+
- MySQL 8.0

## 启动指南

### 后端服务
```bash
cd backend
mvn spring-boot:run
```

### 前端应用
```bash
cd frontend
npm install
npm run dev
```

## 技术栈
- 后端: Spring Boot 2.7.x + MybatisPlus 3.5.x
- 前端: Vue 3.x + Vite
- 数据库: MySQL 8.0
